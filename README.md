# Склад препаратов

Простое веб-приложение (PWA) для учёта остатков препаратов на iPhone. Работает офлайн, данные хранятся на самом телефоне.

## Возможности
- Добавление препарата: название вводится вручную, плюс количество и единица измерения
- Кнопки **+** и **−** на карточке. Нажатие на число открывает приход или расход сразу на нужное количество
- Минимальный остаток: позиции, где остаток ниже минимума или равен нулю, подсвечиваются красным
- Срок годности: просроченные позиции подсвечиваются красным, а те, что истекают в ближайшие 30 дней, оранжевым
- Поиск, фильтры «Мало на складе» и «Срок годности»
- Резервная копия в JSON и восстановление из неё (меню «⋯»)

## Запуск на компьютере
```sh
python3 -m http.server 8000
```
Откройте http://localhost:8000

## Публикация на GitHub Pages
1. Создайте на github.com пустой репозиторий `warehouse`.
2. В папке проекта выполните:
   ```sh
   git remote add origin https://github.com/<ваш-логин>/warehouse.git
   git push -u origin main
   ```
3. В репозитории откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Примерно через минуту приложение будет доступно по адресу `https://<ваш-логин>.github.io/warehouse/`.

## Установка на iPhone
1. Откройте ссылку в **Safari**.
2. Нажмите «Поделиться» → **«На экран Домой»** → «Добавить».
3. Запускайте приложение с иконки: оно откроется на весь экран, как обычное.

## Обновление приложения
После изменения файлов увеличьте `CACHE` в `sw.js` (например, `warehouse-v2`) и отправьте изменения на GitHub. Приложение на телефоне обновится после одного-двух перезапусков. Данные при этом сохраняются.

> Данные хранятся только на телефоне. Время от времени сохраняйте резервную копию (⋯ → «Сохранить резервную копию»), например в iCloud Drive.
